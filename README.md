# 🏢 Rentora

> Smart Rental & Property Management Platform

Rentora is a modern full-stack web application designed to simplify rental and property management for landlords, tenants, and property managers.

🚧 **Project Status:** Under Active Development

## Tech Stack

### Frontend
- React (Vite)
- Tailwind CSS
- React Router

### Backend
- Django
- Django REST Framework

### Database
- PostgreSQL
